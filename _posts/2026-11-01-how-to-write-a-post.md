이 블로그는 누구나 쉽게 글을 올릴 수 있어요.

1. GitHub 저장소의 `_posts` 폴더로 이동해요.
2. **Add file > Create new file**을 눌러요.
3. 파일 이름을 `2026-11-20-제목.md` 형식으로 정해요. (날짜-영문제목)
4. 맨 위에 아래 내용을 붙여넣고 글을 써요.

```
---
layout: post
title: "글 제목"
category: "행사"
author: "작성자 이름"
image: /assets/img/사진파일.jpg
---
여기에 본문을 써요.
```

5. **Commit changes**를 누르면 1~2분 뒤 사이트에 자동으로 올라가요.

사진은 `assets/img` 폴더에 업로드한 뒤 `image:` 에 경로를 적으면 대표 이미지로 나와요. 학생 사진을 올릴 때는 꼭 본인 동의를 받아 주세요.
